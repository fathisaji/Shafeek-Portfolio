# Shafeek Ahmad - Finance Professional Portfolio

## Website Overview

**Purpose:** A modern, professional portfolio showcasing Shafeek Ahmad's banking and finance expertise with a sleek dark theme and vibrant green accents.

**Access:** Public - anyone can view the portfolio without login.

## Powered by Manus

This portfolio is built with cutting-edge web technologies for optimal performance and user experience.

- **Performance:** Optimized for fast loading and smooth interactions across all devices

## Using Your Website

### Navigating the Portfolio

The portfolio features a modern, sleek layout with smooth navigation between sections:

1. **Click the navigation menu** at the top to jump to any section (Home, About, Experience, Education, Skills, Contact)
2. **Use the theme toggle** (sun/moon icon) in the top-right to switch between dark and light modes
3. **Scroll naturally** through the page to explore all content with smooth animations

### Main Features

**Download CV:** Click the "Download CV" button on the hero section to get a PDF copy of your complete resume with all qualifications and experience details.

**Circular Profile Frame:** The hero section features an animated circular frame around your profile photo with gradient borders and decorative elements for a modern look.

**Social Links:** Quick access to LinkedIn, email, and phone contact buttons directly from the hero section for easy networking.

**Theme Switching:** Toggle between dark and light modes anytime using the sun/moon icon in the navigation bar. Your preference is automatically saved.

**Professional Sections:** The portfolio includes comprehensive sections for About, Education, Work Experience, Technical Skills, and Professional Skills - all organized with modern card designs.

## Managing Your Website

### Settings & Customization

Access the Management UI to customize your portfolio:

- **General Settings:** Update website title and logo
- **Domains:** Modify your auto-generated domain or bind a custom domain
- **Preview:** View live changes in real-time as you develop
- **Theme:** The portfolio automatically supports both dark and light modes

### Updating Content

To update portfolio content (education, experience, skills, contact info), edit the Home.tsx file in the Code panel. Changes appear immediately on the live preview with hot module reloading.

### Viewing Analytics

Use the Dashboard panel to monitor visitor traffic and engagement metrics for your portfolio.
